# Job Market Analytics Dashboard

A data analytics dashboard built using Streamlit, Pandas, and Plotly to analyze job market trends and insights.

---

## Live Application
https://job-market-dashboard-36b5vjygjhqfmgxnvkznaq.streamlit.app/

---

## Features

- Interactive job search and filtering (location, skills, salary range)
- Key performance indicators (total jobs, average salary, top company, in-demand skills)
- Data visualizations including:
  - Job role distribution
  - Salary trends and distribution
  - City-wise demand analysis
  - Skills demand analysis
  - Experience vs salary insights
- Automated job market insights using data analysis
- Option to download filtered dataset

---

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
